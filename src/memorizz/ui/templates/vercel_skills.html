How agents use these skills

Attach a skill to pin it to an agent: MemoRizz saves its SKILL.md under ~/.memorizz/skills and adds it to the agent's skills. The agent sees it in list_skills and reads it with read_skill when a task needs it. Code in a skill runs only in a sandbox.

An agent with the skills marketplace enabled can also search and fetch skills itself with vercel_skills_search and vercel_skill_fetch.
