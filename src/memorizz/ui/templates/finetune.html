How fine-tuning works in MemoRizz

Decision models follow the System One contract (Jev, Clef, pplx-decider): a state plus a question with named options, answered with a calibrated probability per option. MemoRizz trains them on an embedding model (JevEmbed style: the state as a query, each option as a document) or a small LM that reads lettered options. Memory routing asks which memory store a piece of state belongs in; relevance decides whether a candidate memory helps answer a query.

Embedding models learn to put each query near the memory that answers it; rerankers score (query, memory) pairs so the best evidence ranks first.

Synthetic examples are written by a teacher LLM and kept only when a blind second check (the teacher again, another LLM, or Jev) agrees. Training runs on this machine (Apple GPU, CUDA or CPU) with LoRA, or with Unsloth on an NVIDIA GPU; every run is scored on held-out examples before and after.
