What an archive preserves

All selected taxonomy records, current values, explicit source links, configured delegates, private and shared memories, and available change/context records. History records preserve timestamps, writer attribution and hashes; deleted or older memory values are not reconstructed. Imported changes begin a new write boundary.

Archives are memory copies rather than complete database backups. External files, credentials, model weights, and the harness run database stay outside the archive. An export can overlap concurrent writes. A restore can commit partially if a provider fails; its report identifies how many records were written. Reconnect tools/providers and regenerate embeddings before relying on semantic search.
