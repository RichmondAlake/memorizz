Delegates{% if delegate_ids %} {{ delegate_ids|length }}{% endif %}Other agents this one hands work to

Delegates are other saved agents this agent hands parts of a request to. The agent's model splits each request among them, each delegate works on its part as a subagent, and the agent combines their results. In harness runs each delegate shows as a subagent in the trace. Every delegate makes its own model calls, so delegated requests cost more.
