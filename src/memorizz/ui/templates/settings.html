Set up

  1. Put your memory online. In a terminal, run {{ id_chip('memorizz mcp apps serve --tunnel', 40) }}, or pass --public-url https://… for a fixed address. Keep it running; it prints the server URL.
  2. Grok Bot. Connect apps → Add a custom connector → name it memorizz, type Remote HTTPS, paste the URL (leave the OAuth fields empty), and sign in with a pairing code.
  3. Grok. grok.com/connectors → New Connector → Custom → paste the URL, and sign in with a pairing code.
  4. ChatGPT dots. Plugins → + → Add custom MCP server (Developer mode) → paste the URL, choose OAuth, and sign in with a pairing code. Your dot uses your plugins.
  5. Claude. On claude.ai: Customize → Connectors → Add custom connector → paste the URL. In Claude Code: claude mcp add --transport http memorizz <URL>, then claude mcp login memorizz.

A --tunnel address changes every time it starts, so the apps must be connected again. Use --public-url with a fixed address to keep them.
