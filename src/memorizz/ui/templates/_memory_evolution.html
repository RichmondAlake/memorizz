About this timeline

History starts when recording is enabled. Earlier history and direct backend writes may be unavailable.

The ruler shows when each memory change was recorded. Changes are spaced for readability; gap labels show actual elapsed time. A run label identifies the execution associated with a change. Existing records have unknown execution history.

Solid lines connect recorded versions. Dashed lines follow explicit sources or derivation links. Existing records have unknown historical attribution.
